# EduLearn — Online Learning Platform

EduLearn is a responsive **frontend e-learning website** built from scratch using **HTML, CSS and JavaScript**.

The project is designed like a real online learning platform, with public pages, authentication screens, course browsing, a student dashboard, profile/settings pages, assignments, certificates and legal/help pages.

## ✨ Features

- Responsive landing page
- Course listing and category filtering
- Course details and accordion sections
- Login and registration UI
- Frontend demo authentication using `localStorage`
- Personalized user name, email and avatar initials
- Student dashboard with learning progress
- My Courses, Assignments and Certificates pages
- Profile, Settings and Messages pages
- Contact, About and legal pages
- Light / dark theme toggle with saved preference
- Responsive mobile navigation
- Clean reusable CSS and JavaScript structure
- GitHub Pages friendly — no backend or build step required

## 🛠️ Tech Stack

- **HTML5** — page structure and semantic content
- **CSS3** — responsive layout, components, animations and themes
- **JavaScript (ES6+)** — interactions, filtering, authentication demo, navigation and theme persistence
- **localStorage** — stores demo user and theme data in the browser

## 🚀 Run Locally

No installation or Node.js setup is required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For the best development experience, use **VS Code + Live Server**.

## 🌐 Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all project files while keeping the folder structure unchanged.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub Pages to publish the site.

Because this project is a static frontend, it does not need a server or build command.

## 🔐 Demo Authentication Note

The login/register system is intentionally frontend-only. User details are stored in the browser's `localStorage`.

This is suitable for a college/project demonstration, but it is **not production authentication**. A real application should use a secure backend, password hashing and proper authentication/session management.
